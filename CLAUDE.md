@AGENTS.md

## Stack
- TanStack Start + React 19 + Mantine v9, yarn 4.
- Tooling runs through Vite+ (`vp`): oxlint and oxfmt. There is no ESLint or Prettier.
- Node 24.21.0 (pinned in `.node-version`).

## Commands
- `yarn dev`: dev server on http://localhost:3000
- `yarn check:fix`: format, lint and typecheck, with fixes
- `yarn vitest`: unit tests
- `yarn test`: full gate (check, stylelint, vitest, build)

## Project layout
- `src/routes/`: file-based routes. `__root.tsx` holds the document shell and `MantineProvider`.
- `src/routeTree.gen.ts` is generated by the router plugin. Never edit it by hand.
- `src/theme.ts`: the Mantine theme (`createTheme`).
- `src/components/<Name>/`: one folder per component, with `<Name>.tsx`, `<Name>.module.css`, `<Name>.test.tsx` and `<Name>.story.tsx`.
- Import aliases: `@/*` maps to `src/*`. Tests import `render` and `screen` from `@test-utils`, which wraps components in `MantineProvider`.
- In CSS modules, use the `$mantine-breakpoint-*` variables (defined in `postcss.config.mjs`) for media queries.

## Rules
- Before using a Mantine component or hook, look up its API with the mantine MCP server instead of relying on memory.
- Style only through Mantine: components, style props, the theme and CSS modules. No Tailwind.
- `reference/` is read-only source material. Never import from it or copy its CSS or Tailwind classes.
- Run `yarn check:fix` and `yarn vitest` before calling a task done.
